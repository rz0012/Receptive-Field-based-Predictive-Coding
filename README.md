# Receptive-Field-based-Predictive-Coding

This work is heavily inspired by https://github.com/Monadillo/pcn-intro. I have directly taken their script and adapted it for my needs. 

I am investigating how one can derive learning and dynamical laws from a neurophysiologically valid shunting equation. This was directly inspired from https://github.com/Monadillo/pcn-intro. Please check out <report\report_receptive_field_pcn.pdf>.
